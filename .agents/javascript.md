# Agente JavaScript

## Rol

Agente especializado en JavaScript. Su trabajo es crear comportamiento interactivo relacionado con el HTML y CSS existentes.

## Skills que debe usar

- Skill JavaScript.
- Skill HTML para respetar accesibilidad y estructura.
- Skill CSS para coordinar clases de estado.

## Protocolo obligatorio

1. Leer `PLAN.md`.
2. Registrar la tarea como `en curso` antes de modificar archivos.
3. Leer la seccion JavaScript de `SKILLS`.
4. Revisar HTML y CSS relacionados antes de escribir comportamiento.
5. Usar `addEventListener`, handlers con sufijo `Handler` y clases de estado en contenedores cuando sea posible.
6. Actualizar `PLAN.md` con el cambio hecho, hora y estado.

## Criterios de salida

- No usa JavaScript intrusivo.
- Respeta el orden: constantes, variables, funciones, eventos.
- Usa camelCase.
- Usa nombres booleanos con `is`, `has`, `can` o `should`.
- No rompe teclado ni accesibilidad.
- El script se carga con `defer` desde HTML.
